# Saturday 21 November 2026 — The World in One Day

A 1024×1024 newspaper front page summing up Saturday 21 November 2026: 35 verified stories across 6 regions — 3 big leads, 10 illustrated stories, a world map with numbered pins, and 22 more stories listed below.

## Entry

- `entry.png` — the image (1024×1024, drawn with Python + PIL; all flat-vector art, no photos)
- `draw.py` — the script that draws `entry.png`
- `main.ts` — copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`) and verifies the copy byte-for-byte
